# 0016 — Synthetic activity is deterministic and time-controllable

**Status:** Accepted

The synthetic bank and Nagare World should operate without AI using seeded routines, distributions, schedules and state machines.

A run with the same seed and initial state should be reproducible.

Simulation time must be controllable so environments can run in real time or accelerate months/years of banking activity for testing, economics, risk and lifecycle analysis.
