# Institutional Banking

Institutional is the internal operating model of the bank.

Nagare should not reproduce the fragmented experience typical of legacy banking software. Institutional interfaces should be organized around work: tasks, decisions, queues, exceptions, approvals, investigations and outcomes.

Examples include credit review queues, treasury liquidity positions, settlement obligations, KYC exceptions, reconciliation breaks, fraud investigations and regulatory tasks.

The user should not need to understand Nagare's backend module boundaries to operate the bank.
