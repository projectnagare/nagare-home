# Glossary

## Actor
A human, system, machine actor or external institution capable of performing an authorized task.

## Capability
A banking function exposed through a contract.

## Contract
A stable interface or event definition that describes a capability without prescribing implementation.

## Distribution
A deployable composition of plugins, configuration, policies and interfaces.

## Institutional
The bank's internal operating view.

## Kernel
The minimal runtime that composes and governs Nagare plugins.

## Nagare World
The independently stateful synthetic financial ecosystem around Nagare Bank.

## Plugin
An implementation of one or more Nagare contracts. A plugin may be local or remote.

## Synthetic bank
The continuously running fake financial institution used for development, testing and experimentation.
