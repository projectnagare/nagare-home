# Project Nagare Repository Map

nagare-home is the central idea home.

| Repository | Purpose |
| --- | --- |
| nagare-home | Constitution, architecture, decisions, RFCs and roadmap |
| nagare-design-system | Brand, tokens, UI, icons and design study |
| nagare-contracts | Canonical banking interfaces and schemas |
| nagare-kernel | Minimal plugin runtime |
| nagare-ledger | Native ledger implementation |
| nagare-world | Synthetic external financial ecosystem |
| nagare-simulator | Living synthetic bank and behaviour engines |
| nagare-consumer | Consumer-bank distribution |
| nagare-business | Business-bank distribution |

Additional repositories should be created only when a clear capability boundary exists.

Avoid creating empty repositories merely to mirror an architecture diagram.
