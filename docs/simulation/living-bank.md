# The Living Synthetic Bank

Nagare should exist continuously before it ever handles real money.

The synthetic bank should have customers, businesses, accounts, deposits, loans, cards, merchants, employers, payments, delinquencies, disputes, fraud, treasury positions, financial statements and operational queues.

Most activity should be generated through deterministic seeded simulation, not AI.

A seed should make a run reproducible.

## Real-time mode
Synthetic banking days occur continuously alongside real time.

## Accelerated mode
Time can advance faster to test long-term behaviour, loan books, defaults, liquidity and product economics.

The simulator should deliberately generate failure and exception scenarios, not only happy paths.
