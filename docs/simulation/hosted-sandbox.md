# Hosted Nagare Sandbox

Nagare should eventually be available as a hosted synthetic bank.

A developer should be able to create an isolated environment and receive a fake bank, customers, businesses, accounts, cards, loans, KYC, bureau data, payment rails, API credentials, webhooks and user logins.

The environment should support reset, replay, deterministic seeds, accelerated time, scenario injection, failure injection, API and webhook testing, and ledger inspection.

The goal is not mocked endpoints. It is a complete synthetic financial institution.
