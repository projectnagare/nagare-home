# External Applications

Nagare must be able to connect core capabilities to external applications without leaking implementation details.

Examples include CRM, ERP, treasury platforms, loan-origination systems, collections platforms, customer-service systems, external CBS platforms and finance systems.

These should connect through Nagare contracts and adapters.

A future bank should not have to replace every existing system to adopt Nagare. This allows Nagare to operate both as a greenfield banking stack and as an overlay or modernization substrate.
