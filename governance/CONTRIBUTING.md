# Contributing to Project Nagare

Nagare is architecture-led.

Before proposing implementation work:

1. Read the Constitution.
2. Read the relevant architecture documents.
3. Check the decision log.
4. Check whether an RFC is required.
5. Depend on contracts, not implementations.
6. Keep the kernel small.
7. Preserve deterministic financial truth.
8. Use the official design system for user interfaces.
9. Do not introduce privileged AI pathways.
10. Treat permissions as task-level concerns.
11. Add synthetic external services when new real-world dependencies are introduced.
12. Record major cross-project decisions in nagare-home.

Contributions should make the system more composable, observable and understandable.
