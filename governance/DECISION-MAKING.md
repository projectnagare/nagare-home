# Decision Making

Project Nagare distinguishes three levels of decisions.

## Constitutional
Changes to the core laws of the project require explicit RFC treatment and should be rare.

## Architectural
Changes to contracts, kernel semantics, distributions, authorization semantics and cross-repository behaviour require RFCs.

## Implementation
Local implementation choices may be made within repositories so long as they remain compatible with the Constitution, accepted decisions and RFCs.

## Canonical record
All major cross-project decisions must ultimately be represented in nagare-home. Chats, implementation issues and code comments may provide context, but they are not the canonical long-term record.

When in doubt, prefer a written decision over an implicit convention.
